# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans ma cantine, merci de nous la signaler de manière responsable.

**Contact** : [contact@egalim.beta.gouv.fr](mailto:contact@egalim.beta.gouv.fr)

Merci de **ne pas** ouvrir d'issue publique pour les vulnérabilités de sécurité.

## Délais

- Accusé de réception sous 3 jours ouvrés.
- Première évaluation sous 10 jours ouvrés.
- Correction déployée dès que possible selon la criticité.

## Périmètre

- Application web : [ma-cantine.agriculture.gouv.fr](https://ma-cantine.agriculture.gouv.fr)
- API : `ma-cantine.agriculture.gouv.fr/api/` (documentation : [/swagger-ui](https://ma-cantine.agriculture.gouv.fr/swagger-ui/))

## Hors périmètre

- Attaques par déni de service (DoS/DDoS)
- Ingénierie sociale
- Vulnérabilités sur des dépendances tierces sans impact démontré
