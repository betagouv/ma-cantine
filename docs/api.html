Fonctionnement

Cette API permet de s'interfacer à l'application ma-cantine afin de réaliser les démarches administratives de cantines. Les schémas des modèles de données sont disponibles en bas de page. Vous y retrouverez notamment la liste des champs du volet approvisionnement (approDiagnostic).

Autorisation 🔓

* Les endpoints avec un cadenas ouvert nécessitent une autorisation. Ils sont destinés aux gestionnaires de cantines. * Les endpoints avec un cadenas fermé ne nécessitent pas d'autorisation (ex: canteenStatistics). Ils sont accessibles par tous.

L'API est protégée par le protocole d'autorisation OAuth2 (voir documentation du protocole et documentation du package Django OAuth Toolkit Documentation). Afin d'obtenir une autorisation, il faut :

  1. Avoir un compte de dév sur la plateforme ma cantine. Quand vous créez votre compte, cocher la case "Je suis une développeuse ou un développeur logiciel et j'ai besoin d'accéder aux APIs". Si vous avez déjà un compte et vous ne voyez pas la page de documentation API, il vous faudra cocher cette case sur la page Mon compte
  2. Avoir enregistré votre application sur la plateforme ma-cantine. À ce stade, il vous faut sauvegarder le CLIENT_SECRET qui ne sera plus visible ensuite (seulement la version hashée le sera).
  3. Récupérer le code d'autorisation dans l'url (voir exemple plus bas). Ce code a une durée de vie d'une minute.
  4. Utiliser ce code d'autorisation pour négocier et récupérer un token d'autorisation.
Vous serez ensuite autorisé à utiliser l'API avec vos mêmes droits utilisateur que sur la plateforme.

Tester

⚠️ Important : Les tests se font obligatoirement sur la plateforme de démo (la suite de la doc référencera toujours l'instance de démo). La plateforme de prod est réservée aux données réelles. Vous pouvez utiliser ce swagger pour tester l'API ici ou consulter un exemple d'application en python.

Tester ici

  1. Créer une application (comme décrit au-dessus) avec l'URI de redirection de swagger : https://ma-cantine-demo.cleverapps.io/swagger-ui/oauth2-redirect.html (pensez à changer l'URL pour la production)
  2. Sauvegarder le secret
  3. Ici, cliquez sur le bouton vert Authorize 🔓, et suivez le protocole d'autorisation dans la partie oauth2 (OAuth2, authorizationCode) avec le client_id et client_secret de l'application que vous avez créée. Cette étape va vous renvoyer vers une page 404 de l'application ma-cantine. C'est bon signe ! Vous pouvez alors récupérer le code dans l'URL.
  4. Renseigner le code récupéré depuis l'URL dans la fenêtre Authorize 🔓, partie cookieAuth (apiKey)
