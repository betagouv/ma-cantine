# Architecture Decision Records (ADR)

Ce dossier rassemble les décisions d'architecture importantes du projet : le contexte, la décision prise, les alternatives écartées et leurs conséquences.

Un ADR n'est pas modifié une fois accepté. Si une décision change, on écrit un nouvel ADR qui remplace l'ancien (et on met à jour le statut de l'ancien : « Remplacé par ADR-XXXX »).

## Format

- Nom de fichier : `NNNN-titre-court.md` (numérotation séquentielle)
- Sections : Statut, Contexte, Décision, Alternatives considérées, Conséquences
